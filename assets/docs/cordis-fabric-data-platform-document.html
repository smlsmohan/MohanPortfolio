CORDIS Fabric Data Platform

Microsoft Fabric, Lakehouse, PySpark, Delta tables and Power BI

Summary: A Microsoft Fabric Lakehouse project that organises CORDIS data through Landing, Bronze, Silver and Gold layers for analytics and reporting.

Objective

The goal was to build an analytics-ready CORDIS data platform that can process multiple programmes and source formats, then produce curated tables for Power BI reporting.

Architecture

  • Landing layer for source zip, csv and json files.
  • Bronze layer for structured raw Delta tables.
  • Silver layer for standardised names, data types, country values and status values.
  • Gold layer for fact and dimension tables used in reporting.

Key Work

  • Created metadata-driven ingestion logic.
  • Built PySpark transformations and validation checks.
  • Designed audit logging and row count checks.
  • Prepared Power BI-ready semantic model tables.

Outcome

This platform became the foundation for the CORDIS Research Explorer web app and the portable Python ETL flow.
