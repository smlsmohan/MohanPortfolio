CORDIS Research Explorer

Next.js, Supabase, Python ETL and dashboard analytics

Summary: A web application that turns cleaned CORDIS research project data into a searchable discovery platform with filters, dashboards and a research chat interface.
82,370project records
3programmes
Liveweb app

Objective

The project converts a large public research dataset into a practical web product. The final data is loaded into Supabase and presented in a Next.js interface for project discovery and reporting.

Features

  • Search by project title, topic, organisation and country.
  • Filters for programme, status, country, role, year and budget.
  • Dashboard cards and visual summaries for research analysis.
  • Guest usage flow and signed-in access.
  • Research chat interface across the app.

Engineering Work

I created the data preparation flow, loaded the cleaned project table into Supabase, built the React components, reduced slow database queries and deployed the app on Vercel.

Outcome

The final result demonstrates full-stack data product development, including ETL, database design, dashboard thinking, authentication flow and production deployment.
