Summary

This project converts a large public research dataset into an easy-to-use discovery tool for projects, countries, organisations, roles, programmes and research areas.

Detailed Explanation

  • Cleaned and prepared CORDIS project data for web access.
  • Built the Next.js and Supabase application for search and dashboard views.
  • Implemented guest usage limits and signed-in full access.
  • Created dashboard visuals for programme, status, country, organisation, role and funding views.
  • Reduced expensive Supabase queries to avoid free database timeouts.
  • Deployed the final app on Vercel.
